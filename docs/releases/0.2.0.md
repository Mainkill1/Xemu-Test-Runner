## Xemu Test Runner 0.2.0

This release integrates the local snapshot/QMP readiness work (#69), the native controller foundation (#72), and controller execution (#73). Both downloads are complete self-contained x64 packages; extract the entire archive, not just the runner executable.

### Changes

- Preserve local snapshot-carrier imports and retry bounded QMP readiness timeouts without discarding caller cancellation.
- Bundle `tools/xemu-gamepad` / `tools/xemu-gamepad.exe`; Linux also includes the matching SDL mapping. OS input is separate from the xemu process, with validated applied receipts, exclusive ownership, bounded held-input freshness, and neutral cleanup.
- Keep safe neutral sessions connected across scheduling pauses; stale held inputs still expire after 250 ms. Malformed input, stale sequences, partial input, EOF, worker termination and blocked output remain covered by cleanup tests.
- Preserve existing keyboard/QMP jobs. Native controller mode is explicit and validates its target binding rather than silently falling back to keys.
- Repair Windows native fixture compilation, isolate OS readback from heartbeat production, support the UI's LStick/RStick click aliases, reject malformed input as validation errors, and bind manual named-button requests to the caller's controller session.
- Publish versioned Windows/Linux archives with exact commit provenance, per-file manifests and SHA-256 checksums. Releases are published only after both builds and controller qualification succeed.

### Important qualification boundaries

Linux native controller use requires access to the built-in uinput interface and a validated private xemu port binding. Native Windows xemu binding remains deliberately unavailable pending target qualification; Windows 10 InputInjector capability refusal remains tracked separately. The Windows runner's existing non-native input paths remain available. An OS-level SDL/XInput readback pass is not proof of guest-game input consumption.

The Steam Deck neutral-stall regression is repaired in code and exercised in automated tests. A new exact-release Deck/game repeat is still required before closing #76 or claiming PGR2 qualification. This release does not include unpublished local PGR2 fixtures or snapshot/XISO tooling from another agent's workspace.

### Upgrade

Finish or explicitly stop active work before replacing the runner. Back up the existing configuration and workspace. Extract the platform archive into a separate application directory, preserving `tools`, `scripts`, and `docs`; use the existing workspace/configuration deliberately rather than replacing them with defaults. Verify `XemuTestRunner --version` (Windows: `XemuTestRunner.exe --version`) against `release.json` and `build-provenance.json`.

No tester baseline, stored result, queue, source HDD, or live emulator configuration is changed by this release. New releases require a reviewed `release-version.txt` change on main; workflow dispatch supports explicit retry without overwriting mismatched existing release assets.
